# 📦 Inventario de Expedición

Sistema de gestión de inventario orientado al control y seguimiento de productos durante el proceso de expedición.

## 🎯 Objetivo

El proyecto busca facilitar la gestión de productos, existencias y expediciones, permitiendo mantener un mejor control de los movimientos de inventario.

## 🚀 Funcionalidades

* 📦 Gestión de productos.
* 📋 Control de inventario.
* 🚚 Registro y seguimiento de expediciones.
* 🔎 Consulta de existencias.
* 📊 Control de movimientos de inventario.
* 👥 Gestión de usuarios *(por definir)*.
